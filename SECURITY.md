# Security Policy — Suraksha

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Suraksha:
- Please report it directly to the lead developer **Dheeraz** via website contact at [dheeraz.dpdns.org](https://dheeraz.dpdns.org/) or by opening a security advisory on GitHub ([github.com/dheeraz101/Suraksha](https://github.com/dheeraz101/Suraksha)).
- Do not disclose vulnerabilities publicly until a fix has been patched.
- Valid reports will be acknowledged within 48 hours.
